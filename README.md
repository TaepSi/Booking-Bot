# Booking-Bot
# 📅 Telegram-бот для записи на услуги

Бот на **aiogram 3.x** + **SQLite**, готовый к деплою на **Render**.

---

## 🗂 Структура проекта

```
tg_booking_bot/
├── main.py          # точка входа (Flask + aiogram)
├── database.py      # вся работа с SQLite
├── keyboards.py     # клавиатуры и форматирование
├── requirements.txt
└── handlers/
    ├── __init__.py
    ├── client.py    # команды клиента
    └── admin.py     # команды администратора
```

---

## ⚙️ Переменные окружения

| Переменная | Описание                                      |
|------------|-----------------------------------------------|
| `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID`  | Telegram `user_id` администратора             |
| `PORT`      | Порт Flask (по умолчанию `10000`)             |

> Узнать свой `user_id` можно через [@userinfobot](https://t.me/userinfobot)

---

## 🚀 Локальный запуск

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Задать переменные окружения
export BOT_TOKEN="your_token_here"
export ADMIN_ID="123456789"

# 3. Запустить
python main.py
```

---

## ☁️ Деплой на Render

1. Создайте **Web Service** (не Background Worker, чтобы работал Flask).
2. Укажите **Start Command**: `python main.py`
3. В разделе **Environment Variables** добавьте `BOT_TOKEN` и `ADMIN_ID`.
4. Render сам установит порт `10000` через переменную `PORT`.

## 🤖 Команды бота

### Клиент
| Кнопка | Действие |
|--------|----------|
| 📋 Услуги | Список всех услуг с ценой и длительностью |
| 📅 Записаться | Запись: услуга → дата → время |
| 🗂 Мои записи | Активные записи + кнопка отмены |
| 📞 Контакты | Контактная информация |

### Администратор (`/admin`)
| Кнопка | Действие |
|--------|----------|
| ➕ Добавить услугу | Пошаговое добавление через FSM |
| 🗑 Удалить услугу | Выбор из списка и удаление |
| 📋 Все услуги | Просмотр всех услуг с ID |

## 🔧 Настройка контактов

Отредактируйте функцию `show_contacts` в `handlers/client.py`:

```python
@router.message(F.text == "📞 Контакты")
async def show_contacts(msg: Message):
    await msg.answer(
        "📱 Телефон: +7 (XXX) XXX-XX-XX\n"
        "📍 Адрес: ваш адрес\n"
        ...
    )
```

## ✅ Возможности

- Автоматическая генерация слотов с 9:00 до 18:00 с шагом = длительность услуги
- Занятые слоты не показываются клиенту
- Воскресенья исключены из выбора дат
- Администратор получает уведомление о каждой новой записи
- Flask keep-alive предотвращает засыпание сервиса на Render
